## 🎯 Day 2 challenge
Create a new file `shopping.py` that:
1. Has a list of at least 3 shopping items, each a dictionary with `name` and `price`.
2. Loops through them and prints each item like: `Milk - $2.50`
3. Adds up and prints the **total cost** at the end.

Bonus: use `input()` to let the user add one more item before showing the total.

If it runs and shows the right total — Day 2 done. ✅

## Key idea to remember
> **List** = things in order (use a number position).
> **Dictionary** = things with labels (use a key name).
> **Loop** = do something to each one.

You'll use these three together constantly. `05_combine.py` is the pattern to memorize.
