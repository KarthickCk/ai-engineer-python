## 🎯 Day 3 challenge — a tip calculator
Create a new file `tip_calculator.py` that:
1. Has a function `calculate_tip(bill, percent)` that returns the tip amount.
2. Has a function `calculate_total(bill, tip)` that returns bill + tip.
3. Asks the user for the bill amount and tip % using `input()`.
4. Prints the tip and the final total, nicely formatted (e.g. `$12.50`).

Bonus: if the bill is over 1000, print "Big spender! 💰".

If it runs and the math is right — Day 3 done. ✅

## Key idea to remember
> A **function** = a named recipe you write once and reuse.
> `return` gives a value back so you can use the result elsewhere.
> `if/elif/else` lets your code choose different paths.

Everything you build from now on — including your AI chatbot — is just functions
making decisions and calling other functions. You're building the core skill today.
