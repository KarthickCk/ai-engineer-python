# Week 1 · Day 1 — Python Basics

Welcome to Day 1! 🎉 Everything you need is in this folder.

## How to run a script
1. Open the Terminal app.
2. Go to this folder:
   ```
   cd /Users/karthick/Documents/AI/python/week01-python-basics/day1
   ```
3. Run a script:
   ```
   python3 01_hello.py
   ```

## Do these in order (about 4 hours)
- [ ] `01_hello.py` — your first program. Run it, then change the text.
- [ ] `02_variables.py` — storing values. Change them to your own info.
- [ ] `03_numbers.py` — math. Predict each result before running.
- [ ] `04_strings.py` — text. Do the "TRY IT" at the bottom.
- [ ] `05_input.py` — interactive! This one asks YOU questions.

**Read each file top to bottom** — the comments (lines starting with `#`) explain everything.
After running each one, do the `# TRY IT:` challenge at the bottom.

## 🎯 Day 1 challenge (do this last)
Create a new file `my_intro.py` in this folder. Make it:
1. Store your name, age, and dream job in variables.
2. Ask the user for their name using `input()`.
3. Print a friendly message using an f-string that includes both names.

Run it with `python3 my_intro.py`. If it works — you crushed Day 1. ✅

## Tip
Made a mistake and got a red error? That's normal — read the LAST line of the
error, it usually tells you what's wrong. Errors are how you learn.
