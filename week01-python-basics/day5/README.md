## 🎯 What you're building
A menu-driven command-line app that lets you:
1. **Add** a task
2. **List** all tasks (numbered)
3. **Remove** a task by its number
4. **Quit**

And — like the note saver — your tasks **persist to a file** (`tasks.txt`),
so they're still there next time you run the app.

| functions | Day 3 | one function per action (add/list/remove) |
| `if/elif/else` | Day 3 | reacting to the user's menu choice |
| files | Day 4 | saving & loading `tasks.txt` |
